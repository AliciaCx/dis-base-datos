
# Diseño y Gestión de Bases de Datos: Tienda de Cosméticos

## Descripción

Este proyecto consiste en el diseño y desarrollo de una base de datos para una tienda de cosméticos, con el objetivo de organizar la información relacionada con los productos y las diferentes categorías de la tienda.

A lo largo del trabajo se aborda el diseño conceptual y la implementación de una base de datos relacional, así como la realización de consultas mediante SQL y operaciones con bases de datos NoSQL.

Además, se utiliza Microsoft Access para diseñar formularios.

## Objetivos

- Diseñar una estructura organizada para almacenar información.
- Identificar las entidades, atributos y relaciones de la base de datos.
- Elaborar el diseño conceptual de la base de datos.
- Implementar y gestionar bases de datos relacionales.
- Realizar consultas para insertar, modificar, eliminar y recuperar información.
- Trabajar con bases de datos NoSQL mediante MongoDB.
- Diseñar formularios en Microsoft Access para facilitar la consulta de información.

## Herramientas utilizadas

- **SQL**
- **MySQL**
- **MySQL Workbench**
- **MongoDB**
- **NoSQLBooster**
- **Microsoft Access**

## Desarrollo del proyecto

1. **Diseño conceptual**
   - Identificación de las entidades y sus atributos.
   - Definición de las relaciones entre las entidades.
   - Elaboración del modelo conceptual de la base de datos.

2. **Implementación de la base de datos**
   - Creación de las tablas.
   - Definición de claves primarias y relaciones.
   - Organización de la información de la tienda.

3. **Consultas SQL**
   - Recuperación de información.
   - Filtrado y ordenación de datos.
   - Realización de consultas sobre las diferentes tablas.
   - Gestión y modificación de registros.

4. **Bases de datos NoSQL**
   - Trabajo con MongoDB para gestionar información mediante una base de datos no relacional.
   - Realización de consultas y operaciones utilizando NoSQLBooster.

5. **Diseño de formularios en Microsoft Access**
   - Elaboración de formularios para introducir y visualizar información.
   - Diseño de interfaces para facilitar la interacción con los datos.

## Elementos desarrollados

El proyecto incluye diferentes elementos relacionados con el diseño y la gestión de bases de datos:

- Diseño conceptual de la base de datos.
- Estructura de tablas y relaciones.
- Consultas SQL.
- Consultas y operaciones con MongoDB.
- Formularios diseñados en Microsoft Access.

## Resultados

El proyecto permitió aplicar conocimientos de diseño y gestión de bases de datos a un caso práctico relacionado con una tienda de cosméticos.

Se desarrolló una estructura organizada para almacenar la información, estableciendo relaciones entre las entidades y realizando consultas mediante SQL y MongoDB.

Además, se diseñaron formularios en Microsoft Access para facilitar la introducción y visualización de la información.

## Cómo consultar el proyecto

Los scripts, consultas y archivos del proyecto pueden consultarse directamente desde GitHub.

Para trabajar con los archivos será necesario disponer de MySQL y MySQL Workbench para la parte relacional, MongoDB y NoSQLBooster para las operaciones NoSQL, y Microsoft Access para visualizar los formularios diseñados en este programa.
